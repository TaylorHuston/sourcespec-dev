# Todo example

A small Vite + React + TypeScript app for trying SourceSpec against real functions and UI events. Add, complete, or remove a task. Todos are stored in a local SQLite file at `.data/todos.sqlite`, so they survive reloads and dev-server restarts. There is no external service or browser storage.

`openapi.yaml` at the app root is the canonical HTTP contract for `/api/todos` (operations, inputs, outputs, and error responses). `npm test` validates the HTTP contract and checks that behavior-case links resolve to the function and test catalogs. `.sourcespec/catalogs/functions-catalog.yaml` inventories **every app-owned function definition**, including anonymous callbacks in runtime, config, and test files. It is generated by `../../tools/function-catalog.mjs`. Function `location` is a file path, not a line number; anonymous entries use `name: null` and a searchable `context`. The generator preserves existing IDs and prose when it can match a function without ambiguity, and gives new functions opaque UUID-based IDs. Older position-shaped IDs remain unchanged to preserve links, but source offsets are no longer stored or used after migration. Moves, renames, and ambiguous callback changes require human reconciliation. `return.type` is a concise call return type (for example `Todo | null`, `Promise<Todo>`, or `object` for an anonymous structural object), not a fully expanded inferred type; declared/curated named types remain meaningful. `.sourcespec/catalogs/tests-catalog.yaml` is still hand-authored and records component, API, and contract tests. `.sourcespec/behaviors/add-task.yaml` describes Add task cases using `../../schema/behaviors.yaml`: each case states its condition and intended outcomes, with curated function pointers for debugging and tests intended to check it. Those links are neither an ordered/exhaustive call trace nor evidence of a passing test run.

Keep one behavior per file under `.sourcespec/behaviors/`, scoped to one trigger and its meaningful cases. There is no fixed line limit: split a behavior when it takes on a different goal or trigger. Cases do not prescribe a sequence, and the HTTP payload/response contract belongs in OpenAPI rather than in behavior records. YAML filenames use kebab-case. An index can be generated later.

Requires Node.js 26+ for the built-in `node:sqlite` module. Vite hosts the local API at `/api/todos` during development and preview; it creates the ignored database file automatically. This is a single-user local experiment, not a deployed service.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Run `npm test` for component, API, and contract tests, `npm run build` to type-check and build, or `npm run preview` after building to serve the build with the same local API. Both tests and builds run `npm run catalog:check`; after changing app code, run `npm run catalog:refresh` and review any ID changes before verifying. Stop the server before removing `.data/todos.sqlite` if you intentionally want to reset your local tasks.
